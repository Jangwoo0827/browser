# 프롬프트 5 계획 — 워크스페이스 + 광고 차단 (확장 방식)

소스 수정 없이 번들 MV3 확장 2개로 구현한다. 각각 별도 브랜치(`workspaces`, `adblock`)에서 작업하고 확인 후 main에 병합한다.

## 1) 워크스페이스 (`extensions/workspaces`)

**조사 결론:** Chrome에는 "탭 숨기기" API가 없고, Opera처럼 워크스페이스별 별도 탭 스트립도 확장으로는 불가. 대신 기존 **탭 그룹**을 워크스페이스로 쓴다.

- 워크스페이스 = 이름·색이 같은 탭 그룹(창마다 하나). 활성 워크스페이스의 그룹만 펼치고 나머지는 **접어서** 탭 스트립에서 사실상 숨김.
- 새 탭은 자동으로 활성 워크스페이스 그룹에 들어간다. 고정 탭(pinned)은 모든 워크스페이스에 공통.
- 전환: 툴바 팝업(목록 클릭), 단축키(`Alt+Q` 다음 워크스페이스, 변경은 `chrome://extensions/shortcuts`).
- 관리: 팝업에서 추가/이름 변경/삭제(삭제 시 탭은 첫 번째 워크스페이스로 이동).
- 기본: `개인`, `업무` 두 개. 기존 탭은 `개인`으로.
- 권한: `tabs`, `tabGroups`, `storage`.
- 한계: 탭 스트립 UI 자체는 그대로(접힌 그룹 칩이 보임). 브라우저 재시작 후 그룹은 제목으로 다시 매칭. 워크스페이스는 창별로 독립 동작.

## 2) 광고 차단 (`extensions/adblock`)

**조사 결론:** MV3의 `declarativeNetRequest`(DNR) 정적 규칙 세트가 기본. 네트워크 필터(`||domain^` 등)는 변환 가능하고, 요소 숨김(`##`)/스크립틀릿/`$csp`/`$redirect`는 변환하지 않는다(→ YouTube 영상 광고 같은 건 못 막음).

- 필터 리스트: EasyList, EasyPrivacy, List-KR(한국). `scripts/update-filters.mjs`가 내려받아 DNR JSON으로 변환 → `extensions/adblock/rules/*.json`.
- 변환기: ABP 문법(`||`, `|`, `^`, `*`) → `urlFilter`, `$third-party`/`$domain=`/리소스 타입 → 조건, `@@` → `allow`(우선순위 높음). 정규식·미지원 옵션은 버림.
- 사이트별 끄기: 동적 `allowAllRequests` 규칙. 팝업에서 현재 사이트 토글, 리스트별 켜기/끄기, 아이콘 배지로 차단 수 표시.
- **한계(Chrome 규칙 수 제한):** 확장당 정적 규칙 30,000개까지는 보장, 그 이상은 전역 풀(330,000)에서 남는 만큼만 사용 → 리스트별로 규칙을 상한 내에서 우선순위(도메인 앵커 규칙 우선)로 잘라 넣고, `getAvailableStaticRuleCount`로 확인. 활성 정적 규칙 세트 수에도 상한이 있음(현재 리스트 3개로 충분).
- **업데이트:** `node scripts/update-filters.mjs` 실행 → 커밋 → 확장 갱신(재실행). 런타임 자동 갱신은 동적 규칙 한도(30,000)가 작아 2차 과제.
