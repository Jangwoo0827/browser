# Fjord 기능 체크리스트와 로드맵

기준 인벤토리: Chrome / Firefox / Opera·GX / Edge / Brave 대표 기능 (사용자가 정리한 22개 영역). 대상은 **Electron 앱(`app/`)** 이다.
표기: ✅ 구현·테스트됨 · 🔶 일부 · ⬜ 예정 · ⛔ 이 구조에서 어렵거나 서버/라이선스가 필요(이유 표기) · 🧩 기존 Chromium+확장 빌드에서만 가능
우선순위: P0 기본기 · P1 실사용 필수 · P2 경쟁력 · P3 차별화/고비용. 마일스톤(M1~M6)은 맨 아래.

## 솔직한 전제 (Electron이라서 달라지는 것)
- 탭 UI, 창, 기록, 북마크, 다운로드, 설정, 권한 UI는 전부 우리가 만든다. 엔진(Chromium)은 렌더링·네트워크·웹 표준을 맡는다.
- **Chrome 확장은 대부분 안 돌아간다**(Electron은 확장 API 일부만 구현). 확장이 맡던 기능(광고 차단, Claude, 워크스페이스)은 앱 안에 직접 구현한다. 13번 영역은 대부분 ⛔/🧩.
- **서버가 필요한 것**: 동기화, 번역(Google 번역 API 키 필요 — 아니면 페이지 번역 서비스로 연결), 안전 브라우징 DB, 비밀번호 유출 점검, VPN. 동기화는 이 PC의 자체 BaaS(supabasebutno)로 가능하지만 종단간 암호화 설계가 선행되어야 한다.
- **DRM(Widevine)**: 표준 Electron에는 없다(castlabs 등 별도 빌드 필요). 넷플릭스류는 당분간 ⛔.
- **보안 업데이트**: Chromium 보안 패치 = Electron 버전 올리기. 정기 점검 절차가 필요하다.

## 1. 기본 탐색 및 컨트롤
- ✅ P0 주소창(URL/검색 겸용), 뒤로/앞으로/새로고침/중지, 새 탭·탭 닫기, 링크 새 탭 열기, 주소 입력 후 이동
- ✅ P0 링크 주소 복사·링크 새 탭 열기(우클릭 메뉴), 로딩 표시·favicon
- 🔶 P0 홈페이지 버튼·홈 설정 · ✅ 보안 상태(자물쇠) 표시 · ⬜ 새 창 열기/닫기 → M2 · ⬜ URL 드래그 앤 드롭 → M2
- ✅ P1 주소창 자동완성(기록·고정 사이트), 페이지 내 찾기(개수·이전/다음), 확대/축소, URL/검색어 판별
- ✅ P1 검색엔진 선택·직접 입력 (키워드 ⬜ M2) · 북마크/열린 탭 기반 제안 → M1a/M1b · 사이트별 줌 기억 → M2 · ✅ 전체 화면(F11) · 🔶 인쇄(Ctrl+P, PDF 저장 ✅ / 미리보기 ⬜) · 페이지 저장 → M2 · URL 공유 → M3

## 2. 탭 스트립 및 탭 관리

- ⬜ P0 탭을 창 밖으로 끌어 새 창/다른 창으로 이동 → M2
- ⬜ P1 닫은 탭 복원, 복제, 고정, 음소거·오디오 표시, 오른쪽/다른/왼쪽 탭 닫기, 탭 검색, 다중 선택 → M1a(다중 선택은 M3)
- ✅ P1 탭 우클릭 메뉴(일부), 탭 전환 단축키(Ctrl+Tab, Ctrl+숫자)

| **M1 필수 기본기** | 닫은 탭 복원·탭 고정/복제/음소거/다른 탭 닫기·탭 검색, 북마크(별·바·관리), 설정 페이지(검색엔진·시작·테마·홈), 인쇄·전체 화면, 창 상태 복원·크래시 복구, 권한 프롬프트·인증서 오류·팝업 차단·보안 상태 표시 | P0 거의 전부 + P1 핵심 |
